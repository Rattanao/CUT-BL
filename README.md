# CUT BL — ตัด B/L → ชื่อไฟล์_PORTAL.txt

ตัด (ลบ) ช่วง B/L ที่ไม่ต้องการออกจากไฟล์ HMAN EDI (เช่น `KMGY_2608S__THLCH_HMAN95.txt`) ให้เหลือเฉพาะส่วนที่ไม่ได้ตัด

## สิ่งที่โปรแกรมทำ

- ลบตั้งแต่บรรทัด **H02** ของ **เริ่มตัด B/L** (เช่น `HASLC03260602093`)
- จนถึงบรรทัดสุดท้าย (H03 … H10) ของ **ถึง B/L** (เช่น `HASLC03260701048`) รวม sub-B/L (`…048A`) ด้วย
- B/L ก่อนและหลังช่วงนี้เก็บไว้ทั้งหมด
- **หรือ เก็บเฉพาะ B/L**: ใส่ B/L ที่ต้องการเก็บ 1 ตัวหรือหลายตัว คั่นด้วย `,` (เช่น `HASLJ01260800588,HASLK02261000346`)
  เก็บเฉพาะ B/L เหล่านี้ (รวม sub-B/L) ตามลำดับในไฟล์ B/L อื่นตัดทิ้งทั้งหมด · ใช้ได้ทีละแบบ · เว้นว่างทุกช่อง (Python: `--all`) = ไม่ตัด แก้ H05 / H07 อย่างเดียว
- **ทุก B/L ที่เหลือ**: `H05` (consignee) = ชื่อเดียวกับ `H06` (notify) เว้นวรรค 1 เคาะเท่านั้น (`H05TH` คงไว้, `H06` ไม่แก้)
- **ทุก B/L ที่เหลือ**: `H07` หน่วยหีบห่อ `PG` → `PX` (เช่น `H070000100PG` → `H070000100PX`)
- บรรทัดหัวไฟล์ `HOU…` และ `H01` เก็บไว้เสมอ (ถ้าไม่มี โปรแกรม ECS-Manifest จะขึ้น "This file is invalid MMAN Text File")
- พิมพ์ `HASLC…` หรือ `H02HASLC…` ก็ได้ · เว้นว่างช่องเริ่มตัด = ตั้งแต่ H02 แรก · เว้นว่างช่องถึง = ถึงบรรทัดสุดท้าย
- ชื่อไฟล์ที่ได้ = ชื่อไฟล์ต้นฉบับก่อน `__` ตามด้วย `_PORTAL` เช่น `KMGY_2608S_PORTAL.txt` อยู่ใน `output/`
- ไบต์และการขึ้นบรรทัด (CRLF) คงเดิม ไฟล์ต้นฉบับไม่ถูกแก้ไข

## วิธีใช้ 1: หน้าเว็บ

เปิด <https://rattanao.github.io/CUT-BL/> (หรือ `index.html`) → เลือกไฟล์ HMAN (.txt) → ใส่ เริ่มตัด B/L / ถึง B/L **หรือ** เก็บเฉพาะ B/L → กด **ตัด B/L** → ตรวจตาราง (ตัดออก / เหลือ) → กด **ดาวน์โหลด**

## วิธีใช้ 2: คำสั่ง Python

```
7-cut bl-portal/
├─ cut_bl.py
├─ input/    ← วางไฟล์ .txt 1 ไฟล์
└─ output/   ← ได้ KMGY_2608S_PORTAL.txt ที่นี่
```

```bash
python cut_bl.py HASLC03260602093 --to HASLC03260701048
```

เก็บเฉพาะ B/L ที่ระบุ:

```bash
python cut_bl.py --keep HASLJ01260800588,HASLK02261000346
```
